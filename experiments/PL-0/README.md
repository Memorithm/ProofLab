# PL-0 — Trusted Infrastructure

PL-0 validates the research substrate itself. It does not search for novel mathematics.

The initial controls are:

1. a known-valid Lean theorem must be accepted;
2. a known-invalid Lean file must be rejected once the negative fixture lands;
3. claim identity must be deterministic and content-sensitive;
4. proof status must remain independent of determinism metadata;
5. toolchain revisions must be explicit.
